## 📈 Key Formulas Reference Across the Course

### 1. Economics (Lecture 02)
$$\text{Price Elasticity of Demand } (E_d) = \frac{\% \Delta Q}{\% \Delta P} = \frac{(Q_2 - Q_1) / Q_1}{(P_2 - P_1) / P_1}$$
$$\text{Average Total Cost } (ATC) = \frac{\text{Total Cost } (TC)}{Q} = \text{Average Fixed Cost } (AFC) + \text{Average Variable Cost } (AVC)$$
$$\text{Marginal Cost } (MC) = \frac{\Delta TC}{\Delta Q}$$

### 2. Financial Accounting (Lecture 04)
$$\text{Assets} = \text{Liabilities} + \text{Equity}$$
$$\text{Current Ratio} = \frac{\text{Current Assets}}{\text{Current Liabilities}} \quad (\text{Benchmark: } \ge 1.5 - 2.0)$$
$$\text{Net Profit Margin } (NPM) = \frac{\text{Net Profit}}{\text{Revenue}} \times 100\%$$
$$\text{Return on Equity } (ROE) = \frac{\text{Net Profit}}{\text{Total Shareholders' Equity}} \times 100\%$$
$$\text{Debt-to-Equity Ratio } (D/E) = \frac{\text{Total Liabilities}}{\text{Total Shareholders' Equity}}$$

### 3. Digital Marketing (Lecture 05)
$$\text{Customer Acquisition Cost } (CAC) = \frac{\text{Total Marketing \& Sales Spend}}{\text{Number of New Customers Acquired}}$$
$$\text{Click-Through Rate } (CTR) = \frac{\text{Total Clicks}}{\text{Total Impressions}} \times 100\%$$
$$\text{Conversion Rate } (CR) = \frac{\text{Total Conversions}}{\text{Total Visitors / Clicks}} \times 100\%$$
$$\text{Customer Lifetime Value } (CLV) = \text{Average Purchase Value} \times \text{Purchase Frequency} \times \text{Customer Lifespan}$$

### 4. Earned Value Management - EVM (Lecture 10 & 11)
$$\text{Cost Variance } (CV) = EV - AC \quad (\text{Positive } = \text{Under Budget})$$
$$\text{Schedule Variance } (SV) = EV - PV \quad (\text{Positive } = \text{Ahead of Schedule})$$
$$\text{Cost Performance Index } (CPI) = \frac{EV}{AC} \quad (> 1.0 = \text{Cost Efficient})$$
$$\text{Schedule Performance Index } (SPI) = \frac{EV}{PV} \quad (> 1.0 = \text{Ahead of Schedule})$$
$$\text{Estimate at Completion } (EAC) = \frac{BAC}{CPI}$$

### 5. Schedule & PERT (Lecture 11)
$$\text{Beta / PERT Duration } (T_e) = \frac{O + 4M + P}{6}$$
$$\text{PERT Standard Deviation } (\sigma) = \frac{P - O}{6}$$
$$\text{Total Float (Slack)} = LS - ES = LF - EF$$

### 6. Risk & Quality (Lecture 12)
$$\text{Qualitative Risk Score} = \text{Probability } (1–5) \times \text{Impact } (1–5)$$
$$\text{Expected Monetary Value } (EMV) = \text{Probability } (P) \times \text{Financial Impact } (I)$$
$$\text{Cost of Quality } (CoQ) = (\text{Prevention} + \text{Appraisal}) + (\text{Internal Failures} + \text{External Failures})$$
