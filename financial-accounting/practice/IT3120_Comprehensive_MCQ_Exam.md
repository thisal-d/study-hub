| **1** | **B** | $\text{Assets} = \text{Liabilities} + \text{Equity}$ (Fundamental equation) |

| **3** | **B** | Revenue is top line of the income statement |
| **4** | **C** | Bottom line = Net Profit after all expenses |
| **5** | **C** | Patents/IP are non-physical intangible assets |
| **6** | **C** | Current assets convert to cash within 1 year |
| **7** | **C** | Accounts payable is short-term debt due within 1 year |
| **8** | **B** | $\text{Equity} = 500,000 - 180,000 = \text{LKR } 320,000$ |
| **9** | **C** | Bank loans are liabilities, not equity |
| **10** | **B** | $\text{Gross Profit} = 100,000 - 60,000 = \text{LKR } 40,000$ |
| **11** | **A** | $\text{Operating Profit} = 40,000 - 20,000 = \text{LKR } 20,000$ |
| **12** | **B** | $\text{Operating Profit} = \text{Gross Profit} - \text{Operating Expenses}$ |
| **13** | **B** | Purchasing long-term fixed assets is an Investing Activity |
| **14** | **C** | Receiving or repaying bank loans is a Financing Activity |
| **15** | **A** | $\text{Operating Cash Flow} = +80,000 - 50,000 = \text{LKR } 30,000$ |
| **16** | **B** | Delayed cash collection creates a liquidity crisis despite book profit |

| **18** | **B** | 2:1 means LKR 2 of liquid assets per LKR 1 of current debt |

| **20** | **C** | Gearing / Leverage ratio measures debt reliance vs equity |

| **22** | **B** | Massive telecom network CapEx is financed through long-term debt |
